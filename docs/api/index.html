Module: simulations/equations.py

Core equations for propulsion calculations, including magnetic fields, RG flows, force/thrust, power/efficiency, and MADA convergence validation. Expansions include non-ballistic trajectories, Monte Carlo, battery models, stealth range, and thermal/TEG simulations.

Constants defined: CONVERGENCE_OPTIMAL = 0.95, CONVERGENCE_WARNING = 0.85, CONVERGENCE_CRITICAL = 0.80

🆕 Function: calculate_convergence_quality(B1, B2)

CRITICAL: Calculate how well MADA magnetic fields are opposing (converging at focal point).

Parameters:
• B1 (np.array): Magnetic field vector from MADA unit 1 [Bx, By, Bz] (T)
• B2 (np.array): Magnetic field vector from MADA unit 2 [Bx, By, Bz] (T)

Returns: float: Convergence quality [-1, 1]
• 1.0 = Perfect opposition (fields pointing directly at each other) ✅
• 0.0 = Perpendicular fields
• -1.0 = Parallel fields (both pointing same direction) ❌

Raises: ValueError if either field vector has zero magnitude
Usage: This is the PRIMARY function for detecting magnetic field misconfiguration. Quality < 0.8 indicates critical failure (fields diverging instead of converging).

🆕 Function: validate_mada_convergence(B1, B2, threshold=0.85, raise_on_fail=False)

Validate that MADA fields are properly converging with detailed status reporting.

Parameters:
• B1, B2 (np.array): Field vectors from MADA units [Bx, By, Bz] (T)
• threshold (float): Minimum acceptable quality (default 0.85)
• raise_on_fail (bool): If True, raise ValueError on poor convergence

Returns: dict with keys:
• 'quality': float convergence quality
• 'status': str ('optimal', 'acceptable', 'warning', 'critical', 'diverging')
• 'is_valid': bool whether convergence meets threshold
• 'message': str diagnostic message

Raises: ValueError if raise_on_fail=True and convergence below threshold

🆕 Function: calculate_field_at_point(m, position_source, position_target, direction)

Calculate magnetic field vector at a target point from a magnetic dipole.

Parameters:
• m (float): Magnetic moment magnitude (A m²)
• position_source (np.array): Position of magnetic source [x, y, z] (m)
• position_target (np.array): Position where field is calculated [x, y, z] (m)
• direction (np.array): Direction unit vector of magnetic moment [x, y, z]

Returns: np.array: Magnetic field vector at target [Bx, By, Bz] (T)

Formula: B = (μ₀/4π) × (3(m·r̂)r̂ - m) / r³

🆕 Function: opposing_field_with_validation(m1, m2, d, B1_vec, B2_vec, k=1.0)

SAFE VERSION: Calculate opposing field WITH automatic convergence validation.

Parameters:
• m1, m2 (float): Magnetic moments (A m²)
• d (float): Distance between MADA units (m)
• B1_vec, B2_vec (np.array): Field vectors from both MADA units
• k (float): Scaling factor (default 1.0)

Returns: tuple: (B_opposing (float), convergence_info (dict))

Raises: ValueError if convergence quality < CONVERGENCE_CRITICAL
Recommended: Use this instead of opposing_field() for safety-critical calculations.

⚠️ Function: opposing_field(m1, m2, d, k=1.0)

Calculate the opposing magnetic field MAGNITUDE.

Parameters:
• m1 (float): Magnetic moment 1 (A m²)
• m2 (float): Magnetic moment 2 (A m²)
• d (float): Distance between MADA units (m)
• k (float): Scaling factor (default 1.0)

Returns: float: Opposing field magnitude B_opposing (T)
⚠️ WARNING: This function does NOT verify field direction! Result is only valid if MADA units are properly configured with fields pointing toward each other (converging at focal point). Use validate_mada_convergence() to verify configuration before relying on this value, or use opposing_field_with_validation() instead.

Example 1: Basic Convergence Check

from simulations.equations import (
    calculate_convergence_quality,
    validate_mada_convergence
)
import numpy as np

# Read from Hall sensors
B1 = np.array([-50.0, 0.0, 0.0])  # MADA 1 field vector (T)
B2 = np.array([50.0, 0.0, 0.0])   # MADA 2 field vector (T)

# Quick quality check
quality = calculate_convergence_quality(B1, B2)
print(f"Convergence quality: {quality:.3f}")

# Detailed validation
result = validate_mada_convergence(B1, B2)
print(f"Status: {result['status']}")
print(f"Message: {result['message']}")

if not result['is_valid']:
    print("⚠️ WARNING: MADA fields not properly opposing!")

⚠️ Critical Reminders for API Users

MADA Convergence Best Practices

  1. Always validate before flight: Run convergence checks during pre-flight calibration
  2. Monitor in real-time: Log convergence quality every control loop iteration
  3. Use safe functions: Prefer opposing_field_with_validation() over opposing_field()
  4. Set thresholds:
    • Quality ≥ 0.95: Optimal operation
    • Quality 0.85-0.95: Acceptable, monitor
    • Quality 0.80-0.85: Warning, reduce thrust
    • Quality < 0.80: Critical, emergency landing
  5. Visualize during development: Use flux_visualizer.py to verify CAD configurations
  6. Test with both configurations: Verify code detects diverging fields (converging=False)

Common Mistakes to Avoid

  • ❌ Using opposing_field() without validating field directions first
  • ❌ Assuming positive thrust values mean correct configuration
  • ❌ Not logging convergence quality during flights
  • ❌ Ignoring convergence warnings during testing
  • ❌ Using scalar Hall sensors instead of 3-axis sensors
  • ❌ Not testing with intentionally wrong configurations
